# Kaps-Cup – Claude Universal Proxy

**Kaps-Cup** is an open-source Claude Universal Proxy designed to make AI more accessible by allowing users to connect Claude-compatible applications, desktop clients, and other AI-powered tools with free and alternative Large Language Models (LLMs).

Powered by **LiteLLM**, Kaps-Cup provides a unified proxy layer that simplifies model connectivity and helps users use different LLM providers without being restricted to a single AI service.

### Key Features

- **Universal Compatibility:** Connect Claude-compatible desktop applications, tools, and other supported clients.
- **LiteLLM Integration:** Use LiteLLM as the unified proxy layer for managing LLM connections.
- **Free LLM Support:** Help users access available free-tier and free-to-use LLM models.
- **Multiple Model Providers:** Support different LLM providers through a common interface.
- **Centralized Configuration:** Manage model connections and proxy settings from one place.
- **Cost-Effective AI:** Reduce dependency on expensive AI subscriptions and API services.

### Project Goal

The goal of Kaps-Cup is simple: make AI accessible to everyone by providing a universal, flexible, and cost-effective way to connect AI applications with different LLM models.

**One Proxy. Multiple Models. More AI Freedom.**
